# Dataset Description

This folder contains the datasets used for training and testing the Gradient Boosting Regression model presented in the article.

## Files

* **train_dataset**: Training dataset used to train the Gradient Boosting Regression model.
* **test_dataset**: Testing dataset used to evaluate the model performance.

## Usage

To reproduce the machine learning results reported in the article, open and run the Jupyter Notebook:

```text
machine_learning.ipynb
```

The notebook will load the provided datasets and perform model training, prediction, and evaluation.

## Notes

* Please keep the dataset filenames unchanged:

  * `train_dataset`
  * `test_dataset`
* Ensure that the datasets are located in the directory expected by the notebook.
* Run all cells in `machine_learning.ipynb` sequentially to reproduce the results presented in the article.
